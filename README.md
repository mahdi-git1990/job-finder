# پروژه پلتفرم کاریابی (Job finder)

این پروژه یک رابط کاربری مدرن و واکنش‌گرا (Responsive) برای یک وب‌سایت کاریابی است که با استفاده از **Tailwind CSS** طراحی و پیاده‌سازی شده است.

## 🚀 ویژگی‌ها
- **طراحی مدرن:** استفاده از قابلیت‌های پیشرفته Tailwind CSS برای ایجاد ظاهری تمیز و کاربرپسند.
- **واکنش‌گرا:** کاملاً بهینه برای نمایش در موبایل، تبلت و دسکتاپ.
- **چیدمان حرفه‌ای:** پیاده‌سازی بخش‌های مختلف از جمله لیست مشاغل، فیلترها و فرم‌های جستجو.
- **عملکرد بالا:** حجم بسیار کم و سرعت بارگذاری عالی.
  **پیاده سازی حالت دارک مود با توجه به تنظیمات سیستم
## 🛠 تکنولوژی‌های استفاده شده
- HTML5
- Tailwind CSS
